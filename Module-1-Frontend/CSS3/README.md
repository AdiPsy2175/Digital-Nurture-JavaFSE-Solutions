# CSS3

This folder contains CSS3 exercises completed as part of the Cognizant Digital Nurture 5.0 Java FSE Program.

## Project Theme

Styling the Local Community Event Portal

## Exercises Covered

1. CSS Introduction and Styling Methods
2. CSS Syntax and Comments
3. Selectors Playground
4. Color and Background Styling
5. Typography and Text Formatting
6. Link and List Styling
7. Table Styling
8. Box Model and Layout Control
9. Multiple Column Layout
10. Responsive Web Design with Media Queries
11. Debugging and Testing with DevTools

## Key Concepts Practiced

* Inline, Internal and External CSS
* Selectors and Specificity
* Colors, Gradients and Background Images
* Typography and Google Fonts
* Box Model
* Tables and Lists Styling
* Multi-Column Layouts
* Responsive Design
* Media Queries
* Chrome DevTools

## Learning Outcome

Learned to create visually appealing, responsive, and maintainable user interfaces using modern CSS3 techniques.
