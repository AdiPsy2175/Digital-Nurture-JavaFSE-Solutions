# Bootstrap 5

This folder contains Bootstrap 5 exercises completed as part of the Cognizant Digital Nurture 5.0 Java FSE Program.

## Objective

Learn how to build responsive and mobile-friendly user interfaces using Bootstrap 5.

## Topics Covered

* Bootstrap Setup and CDN Integration
* Containers and Grid System
* Typography Utilities
* Colors and Background Utilities
* Spacing Utilities
* Borders and Shadows
* Buttons and Button Groups
* Tables
* Forms and Form Controls
* Cards
* Navigation Bars
* Alerts
* Badges
* Progress Bars
* Modal Components
* Responsive Layouts
* Bootstrap Utility Classes

## Key Concepts Practiced

* Mobile-First Design
* Responsive Grid Layout
* Reusable UI Components
* Utility-First Styling
* Responsive Navigation
* Form Design
* Card-Based Layouts

## Learning Outcome

Gained hands-on experience in developing responsive web interfaces quickly using Bootstrap 5 components, utilities, and grid-based layouts.

## Project Integration

The concepts learned in this module were applied in the Local Community Event Portal project to create a responsive and user-friendly interface.
