# HTML5

This folder contains HTML5 exercises completed as part of the Cognizant Digital Nurture 5.0 Java FSE Program.

## Project Theme

Local Community Event Portal

## Exercises Covered

1. HTML5 Base Template
2. Navigation and Linking
3. Welcome Message with Styling and ID/Class
4. Image Gallery for Community Events
5. Event Registration Form
6. Event Feedback with Event Handling
7. Video Invite with Media Events
8. Saving User Preferences
9. Geolocation for Event Mapping
10. Debugging with Chrome DevTools

## Key Concepts Practiced

* Semantic HTML5 Elements
* Navigation and Hyperlinks
* Forms and Validation
* Tables and Images
* Audio and Video Integration
* Local Storage and Session Storage
* Geolocation API
* Event Handling
* Browser Developer Tools

## Learning Outcome

Built the structure of a Local Community Event Portal while gaining hands-on experience with modern HTML5 features and browser APIs.
