# Local Community Event Portal

A web-based portal developed as part of the Cognizant Digital Nurture 5.0 Frontend learning module.

## Project Overview

The Local Community Event Portal helps residents discover, register for, and interact with local community events. The project combines HTML5, CSS3, JavaScript, and Bootstrap concepts learned throughout the frontend module.

## Features

* Event Listings
* Event Registration Form
* Event Image Gallery
* Video Invitations
* Event Filtering and Search
* User Preference Storage
* Geolocation Support
* Responsive Design
* Interactive User Interface

## Technologies Used

* HTML5
* CSS3
* JavaScript
* Bootstrap 5
