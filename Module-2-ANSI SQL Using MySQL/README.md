# ANSI SQL Using MySQL

This folder contains ANSI SQL exercises completed as part of the Cognizant Digital Nurture 5.0 Java FSE Program.

## Project Theme

Local Community Event Portal Database

The exercises are based on a community event management system where users can register for events, attend sessions, provide feedback, and access event resources.

## Database Schema

The database consists of the following tables:

* Users
* Events
* Sessions
* Registrations
* Feedback
* Resources
