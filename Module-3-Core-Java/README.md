# Core Java

This folder contains Core Java exercises completed as part of the Cognizant Digital Nurture 5.0 Java FSE Program.

## Objective

Build a strong foundation in Java programming by covering fundamental concepts, object-oriented programming, exception handling, collections, file handling, database connectivity, networking, and modern Java features.
